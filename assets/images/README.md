# Sea Creature Icons

This folder should contain PNG images of sea creatures with transparent backgrounds.

## Required PNG Files

Place the following PNG files in this directory (assets/images/):

### Animals:
- `fish1.png` - Tropical Fish (Clownfish)
- `fish2.png` - Clownfish (or Whale Shark)
- `turtle.png` - Sea Turtle
- `dolphin.png` - Dolphin
- `whale.png` - Whale
- `shark.png` - Shark
- `octopus.png` - Octopus
- `seahorse.png` - Seahorse
- `jellyfish.png` - Jellyfish
- `crab.png` - Crab
- `pufferfish.png` - Pufferfish

### Plants:
- `seaweed1.png` - Seaweed
- `coral1.png` - Coral
- `coral2.png` - Red Coral
- `kelp.png` - Kelp Forest
- `anemone.png` - Sea Anemone

### Habitats:
- `reef1.png` - Coral Reef
- `cave.png` - Underwater Cave
- `shipwreck.png` - Shipwreck
- `treasure.png` - Treasure Chest

## Image Requirements:
- Format: PNG with transparent background
- Recommended size: 64x64 to 128x128 pixels
- Background: Transparent (no background)
- Style: Cute, cartoon-style sea creatures

The images will automatically scale to fit the display size in the shop and ocean environment.
